# FongMi TV · Android TV 10-foot UI 全局视觉与交互设计规范系统 (v1.2 Baseline)

> **适用平台**：Android TV / Android 盒子 (Leanback)
> **基准分辨率**：1920 × 1080 (1080p FHD, 60fps)
> **视距标准**：2.5 米 – 3.5 米 客厅远距视距 (10-foot Experience)
> **核心输入**：D-pad 遥控器（↑ ↓ ← → / OK / Back / Menu），零触控依赖
> **兼容基线**：Android minSdk 24 (纯原生与轻量化渲染，零外部厚重框架)

---

## 1. 电视画布与安全区 (Layout & Overscan Grid)

电视面板受各品牌显示机制、HDMI 信号裁剪影响，必须设置严格的抗过扫描（Overscan）安全边界。

| 布局属性 | 尺寸 / 规范值 | 视觉说明与约束 |
| :--- | :--- | :--- |
| **物理画布** | `1920 × 1080 px` | 16:9 标准宽屏比 |
| **Overscan 电视安全区** | **72 px (72 dp)** | 四周必须保留 ≥72px 边距，禁止放置任何关键信息、可落焦按钮、文字与图标 |
| **Header 导航高度** | **72 dp (h-18)** | 顶部导航通栏高度，垂直居中排布 |
| **底部快捷提示栏** | **48 dp (h-12)** | 固定居底上方，贴合安全区下边缘 |
| **标准间距梯队** | 4dp / 8dp / 12dp / 16dp / 24dp / 32dp | 基于 4dp 网格律动，跨组件严禁出现随机奇数间距 |

## 2. 核心色彩体系与对比度 (Champagne Dark Palette)

专为 OLED、Mini-LED 及高对比度客厅大屏定制的「香槟金暗黑影院（Champagne Dark）」色系，严格通过 **WCAG 2.1 AA** 级对比度认证（客厅大屏标准建议字文对比 ≥ 4.5:1，关键焦点框 ≥ 3:1）。

### 2.1 颜色令牌对照表

| 令牌名称 (Token) | HEX 色值 | 语义角色 / 适用场景 | WCAG 对比度说明 |
| :--- | :--- | :--- | :--- |
| `background` | `#0E0E10` | 炭黑底色 (OLED 纯净黑背景，杜绝灰朦感) | 极暗背景基底 |
| `surface` | `#131315` | 一级面板 / 卡片默认底色 | 极低对比度隐藏背景 |
| `surface-container` | `#1B1B1D` | 二级容器 / 侧边栏底色 / 弹窗与设置抽屉 | 阶梯层级分离 |
| `surface-bright` | `#28282C` | 三级容器 / 按钮静态底色 (`#202024` 微调) | 与背景对比 ≥ 2.5:1 |
| **`focus` (亮香槟金)** | **`#FCD58B`** | **全局唯一焦点边框、落焦光晕、光标指示** | **对深色背景 8.8:1** (高亮显眼) |
| **`accent` (暖金香槟)** | **`#E5A958`** | **品牌主色、主操作 CTA、VIP/4K 核心标签** | **对深色背景 7.2:1** |
| `text-primary` | `#FFFFFF` | 主标题、关键片名、聚焦项主要文字 | 对 `#131315` **11.2:1** (极清晰) |
| `text-secondary` | `#9E9EA6` | 演职员、副标题、非聚焦元数据信息 | 对背景 **4.8:1** (满足 AA 级) |
| `text-muted` | `#66666E` | 快捷键提示说明、版权版本号、分界装饰 | 静态辅助信息 |
| `success` | `#34D399` | 在线源、硬解直连、EPG 匹配成功、低延迟 | 绿光状态指示 |
| `warning` | `#F59E0B` | 缓冲中、软解占用高、线路切换提示 | 琥珀告警色 |
| `error` | `#EF4444` | 线路超时、接口失效、嗅探失败 | 红色警示 |

## 3. 3 米客厅视距字号阶梯 (10-foot Typography Scale)

大屏电视视距（2.5–3.5 米）下，字号过小会造成视觉疲劳，过大则挤压剧集网格。

| 梯队级别 | 像素值 (px) | 电视 sp 单位 | 建议字重 | 应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Title** | `48–52 px` | `36–38 sp` | Bold (700) | 顶部推荐特惠位影片主标题、全屏播放大片名 |
| **Section Title** | `26–28 px` | `19–20 sp` | SemiBold (600) | 分类排行大标、设置项组名、二级页主标题 |
| **Card Title** | `20–22 px` | `15–16 sp` | Medium (500) | 海报卡片片名、设置列表项主标题、线路名称 |
| **Body / Meta** | `16–18 px` | `12–13 sp` | Regular (400) | 简介正文、演职员信息、播放器当前码率规格 |
| **Caption / Badge** | `13–14 px` | `10–11 sp` | SemiBold (600) | 4K/HDR 标签角标、剧集集数小标、快捷提示按键字 |

> **排版约束**：
> 1. 卡片主标题与副信息间距必须保持 `≥ 6px`，严禁行高塌陷重叠；
> 2. 正文简介行高设定为 `leading-relaxed` 或 `leading-loose`；
> 3. 字体选用无衬线现代屏显字体，优先推荐 `Space Grotesk`、`Inter` 或系统原生 `Roboto / Noto Sans SC`。

## 4. D-pad 遥控器六大核心交互状态 (Focus State Matrix)

电视端无鼠标指针，**任何时刻屏幕上必须且只能存在唯一一个落焦元素（单屏单焦点）**。焦点态必须满足 **「颜色 + 形状 (描边) + 空间 (物理缩放)」** 三维双保险原则。

### 4.1 状态矩阵定义

| 状态类型 | 视觉表现规范 | 交互反馈与语义 |
| :--- | :--- | :--- |
| **1. 默认未聚焦 (Default)** | 背景透明或 `#1B1B1D`，文本 `#9E9EA6`，无外边框 | 低调沉底，避免抢占视觉重心 |
| **2. D-pad 焦点态 (Focused)** | **`3.5dp #FCD58B` 实线描边 + `25px` 柔和金光晕 + `1.05x` 物理缩放** | **最高视觉跳跃层，必须配备 `z-index: 10` 浮层防遮挡** |
| **3. 按下/激活态 (Active)** | 瞬时轻微收敛至 `0.98x` 缩放，内层伴随高亮脉冲光圈 | 确认遥控器 OK 键已成功触发行程 |
| **4. 选中当前项 (Selected)** | 背景浅金半透填充 (`rgba(229,169,88,0.15)`)，左侧带有指示条或勾选 | 标识当前正在播放的线路、所选音轨或配置页面 |
| **5. 空态引导 (Empty)** | 居中高质感纯线性矢量 SVG，文字简明克制，主操作聚焦「导入配置」 | 拒绝留白发懵，遥控器 OK 键直通配置向导闭环 |
| **6. 错误/断流 (Error)** | 告警微红轮廓，配有「重试」与「快速换源」主备双按键 | 错误原因明确（<14字），遥控器直接提供脱困方案 |

## 5. 动效与物理微交互规范 (Motion System)

为避免电视芯片硬件过载，杜绝复杂三方重型动画库，使用 GPU 硬件加速的标准 CSS Transitions / Transforms。

| 动效场景 | 持续时长 (Duration) | 缓动曲线 (Easing) | 属性说明 |
| :--- | :--- | :--- | :--- |
| **卡片落焦过渡** | `180ms – 240ms` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | `transform: scale(1.05)`, `box-shadow`, `border-color` |
| **抽屉/浮层展开** | `250ms – 300ms` | `cubic-bezier(0, 0, 0.2, 1)` (Decelerate) | 侧拉直播节目单、播放器设置菜单水平滑入 |
| **页面切片渐变** | `200ms` | `ease-out` | 页面切换时整屏内容淡入，顶部导航位置绝对固定 |
| **低性能降级** | `0ms` (瞬切) | `none` | 遵循 `@media (prefers-reduced-motion: reduce)` 标准 |

## 6. 核心功能页结构蓝图 (Page Architecture)

1. **Home (首页)**：顶部导航栏 + Hero 每日主推大画报 + 紧凑海报走廊（横版 16:9 / 竖版 2:3 矩阵）。
2. **Detail (详情页)**：左上方 16:9 播放器小窗（5列）+ 右侧影片元数据与快捷操作栏（7列）+ 播放线路/画质/选集三行控制组 + 底部相关推荐。
3. **Player (播放器)**：全屏画面 + 顶部片名与时间 + 底部 10-foot 控制进度条 + 侧拉播放快速调优抽屉（音轨/解码/字幕）。
4. **Live & EPG (直播)**：全屏直播画面 + 左侧浮动频道分组 + 中间展开即时 EPG 时间轴节目单。
5. **Search (搜索)**：T9 / 全键盘双模式软键盘 + 焦点字母即时联想 Chip 胶囊流 + 右侧精准匹配网格。
6. **Settings (系统设置)**：经典 3 栏对齐（左侧 450dp 导航分类 + 中间 6 列配置项开关卡片 + 右侧 3 列局域网扫码推送二维码与说明）。
7. **Collect & History (收藏历史)**：分段式 Tab 切换 + 16:9 进度条卡片 + 一键清空/批量管理功能。
8. **Empty States (空态引导套件)**：未配置点播、未配置直播源、WebDAV 挂载空态等，均提供扫码直连与快速配置入口。

## 7. 遥控器通用按键映射底栏 (D-pad Keycaps Footer)

每个页面底部均采用统一的快捷提示行：
- `▲▼◀▶`：移动焦点
- `OK`：打开 / 播放 / 确认选择
- `Menu`：呼出配置源码 / 快速换源 / 调出菜单
- `Back`：返回上一层 / 保存并退出
